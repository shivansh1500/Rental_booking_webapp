# 🏠 StayHub — Rental Listing Web Application

StayHub is a full-stack rental listing web application where users can explore properties, create and manage listings, upload property images, and share reviews/ratings. The application includes secure authentication, ownership-based access control, and a clean user interface.

---

## 🚀 Features

- ✅ User Authentication (Sign up / Login / Logout)
- ✅ Session-based login system with secure access control
- ✅ Create, Read, Update, Delete (CRUD) for property listings
- ✅ Upload property images using cloud storage
- ✅ Add, edit and delete reviews with ratings
- ✅ Ownership-based authorization (only owners can modify their content)

---

## 🛠️ Tech Stack

**Frontend**
- EJS (Server-side templates)
- Tailwind CSS

**Backend**
- Node.js
- Express.js

**Database**
- MongoDB
- Mongoose

**Authentication & Sessions**
- Passport (Session-based Authentication)
- Express-session

**Image Handling**
- Cloudinary (cloud image storage)
